# 📘 Assignment: Hangman Game Challenge

## 🎯 Objective

Build the classic word-guessing game using Python strings, loops, and user input. You will create a Hangman game where players guess letters to reveal a hidden word before running out of attempts.

## 📝 Tasks

### 🛠️ Implement the Hangman Game

#### Description
Create a Hangman game that allows players to guess letters to reveal a hidden word. The game should randomly select a word, display the current progress, track incorrect guesses, and determine when the player wins or loses.

#### Requirements
Completed program should:

- Randomly select words from a predefined list
- Accept letter guesses and show current progress (_ _ _ format)
- Track incorrect guesses remaining
- End when word is guessed or attempts exhausted
- Display win/lose messages
- Practice string manipulation, loops, and conditionals
